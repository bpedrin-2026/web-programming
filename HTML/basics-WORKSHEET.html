Question 1

What is the significance of the html element in an html document?

The html element is the root element of the document, and it contains all of the other elements of the document.
Question 2

What is the purpose of the head element in an html document?

The head element contains the metadata, title, and links to other resources.
Question 3

What is the purpose of the title element in an html document?

The title specifies the title of the document.
Question 4

What is the purpose of the body element in an html document?

The body element contains the content of the document that is visible to the user.
Question 5

What is the difference between an inline element and a block element?

The difference is that inline elements don't start on a new line when displayed, and block elements get their own line.
Question 6

What is a self-closing tag?

These are tags that are used to add items like images and line breaks, and are not allowed to have any content.
Question 7

Explain the syntax for adding an attribute to an HTML element?

The attribute of an element is added inside the opening tag, and is written with the name of the attribute, followed by an equal sign, and then a value. (ex. <img src="image.jpg">)
