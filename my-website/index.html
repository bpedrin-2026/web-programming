About Me

I'm Benjamin Pedrin, a developer who learns by building. Alongside my coursework, I design and run my own infrastructure — from a home server hosting this site to a self-hosted cloud and a local AI assistant I set up myself. I'm currently developing Project Guardian, a personal-safety app with real-time alerts and emergency tracking, handling everything from the backend logic to the server it runs on.

I come at technology hands-on: picking apart auction hardware, rebuilding workstations into production servers, and learning languages like Python and front-end fundamentals like CSS as I go. I care about understanding how things actually work rather than just getting them running, and I'm always looking for the next project that lets me build something real.
